# ABPG-Pulse-Generator
The PCB project for Low Cost Picosecond Pulse Reference Source with Low Jitter. 

This is the project described in "Low Cost Picosecond Pulse Reference Source with Low Jitter" by Maciej Grzegrzółka and Bartosz Gąsowski. The paper is currently under consideration for publication. Once it will be accepted the link to the paper will be placed here.
